Project 03

这个网站

Three.jsCSSJavaScript

这是我的个人网站，用纯 HTML、CSS 和 JavaScript 手写，没有使用任何框架；3D 部分用 Three.js 实现，所有资源都放在本地。

视觉

  • 毛玻璃材质、柔和分层阴影、缓慢漂移的渐变网格，以及一层颗粒纹理
  • 首页是一个会“呼吸”的 3D 流体球，跟随鼠标转动，点击会泛起波动

交互

  • 弹性曲线驱动的按钮、导航指示块和卡片倾斜
  • 内容随滚动依次渐入；页面切换都在同一个标签页内完成

工程

  • Design Tokens + 标准化组件，详见 组件库
  • 支持深色 / 浅色模式、手机浏览，以及“减少动画”的系统设置
